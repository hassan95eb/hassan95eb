## 🧠 Engineering Principles

```text
Performance is a product feature.
Architecture should reduce future complexity.
The API and the UI should be designed together.
User experience and engineering quality reinforce each other.
```

<p align="center">
<img src="https://readme-typing-svg.demolab.com?font=Inter&weight=500&size=16&duration=2400&pause=1200&color=B96B4A&center=true&vCenter=true&width=750&lines=Performance+is+a+product+feature.;Architecture+should+reduce+future+complexity.;The+API+and+the+UI+should+be+designed+together.;UX+and+engineering+quality+reinforce+each+other." alt="principles" />
</p>

I care deeply about:

* Clear boundaries between application layers, on both sides of the API
* Predictable state and data flow
* Domain-driven layering and testability on the server
* Reusable components without premature abstraction
* Measurable performance improvements
* Accessibility and responsive behavior
* Technical decisions aligned with business goals
